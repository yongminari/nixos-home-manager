# Package Cleanup Handoff

## Context

- Baseline branch: `main`
- Baseline commit: `a41d649 fix(yazi): modernize config and restore file opening`
- Yazi and Zellij have already been reviewed. Yazi was simplified, applied, and verified by opening a file with `Enter`.
- The package audit was performed on `ai-x1-pro` with the current flake lock.
- The evaluated Home Manager package list contained 138 entries. Thirteen package names were duplicated, accounting for 14 redundant list entries.

## Scope Decision

The current Home Manager packages and applications are intentionally shared by all PCs.

- Keep the common imports in `home.nix`.
- Do not introduce host-specific package flags or split Google Cloud, ROS, QMK/Vial, WeeChat, GUI applications, or rclone by host.
- Focus on duplicate declarations, packages already supplied by Home Manager modules, obsolete compatibility tools, and clearly unused alternatives.
- Preserve packages whose usage cannot be determined from static configuration, such as Obsidian, OnlyOffice, Geeqie, WeeChat, ROS tools, QMK/Vial, and rclone.

## Recommended Cleanup

### 1. Remove exact Home Manager duplicates

Use `modules/core/system-utils.nix` as the canonical location for common runtime CLI utilities.

- Remove `ripgrep`, `fd`, and `unzip` from `modules/dev/dev-tools.nix`; they already exist in `modules/core/system-utils.nix`.
- Remove `fastfetch` and `lolcat` from `modules/core/shell/utils.nix`; they already exist in `modules/core/system-utils.nix`.
- Remove `libnotify` from the root `home.packages` in `home.nix`; keep the declaration in `modules/core/system-utils.nix`.
- Remove `pkgs.lolcat` from `modules/core/shell/welcome.nix`; the generated scripts reference `${pkgs.lolcat}` directly.
- Remove `xwayland-satellite` from `modules/desktop/gui-apps.nix`; keep it with the Niri packages in `modules/desktop/niri/default.nix`.
- Remove the explicit `cliphist` package from `modules/core/system-utils.nix`; `services.cliphist.enable = true` supplies it.
- Remove explicit `papirus-icon-theme` and `qt6Packages.qt6ct` entries from `modules/core/theme.nix`; the GTK icon theme and Home Manager Qt module already supply them.
- Do not try to eliminate the evaluated `bibata-cursors` duplicate mechanically. It is produced by Home Manager cursor integrations and does not create a second Nix store copy.

### 2. Simplify redundant tools

- Remove `lua51Packages.jsregexp` from `modules/dev/dev-tools.nix`; Neovim already supplies it through `programs.neovim.extraLuaPackages`.
- Remove `lazydocker` and retain `podman-tui`. The system uses Podman and `virtualisation.podman.dockerSocket.enable` currently evaluates to `false`, so LazyDocker is not correctly supported by the current setup.
- Remove `SwayNotificationCenter` from `modules/core/system-utils.nix`. No SwayNC service or binding is configured, and Noctalia provides the active notification/control center.
- Remove the Alacritty configuration from `modules/desktop/gui-apps.nix`. Kitty is the configured default and Niri launcher target, while Ghostty is retained for its SSH integration.
- Remove `net-tools` from `modules/core/nixos-base.nix`; use the standard `iproute2` commands available on NixOS.
- Remove `htop` completely and retain the configured `btop` plus `procs`.
- Remove `lsb-release` unless a build or verification step reveals a real consumer; the current welcome script reads `/etc/os-release` directly.
- Keep `google-cloud-sdk` as a common package according to the scope decision above.

### 3. Consolidate fonts

- Keep `maple-mono.NF` and `d2coding` in the system-level `fonts.packages` declaration in `modules/core/nixos-base.nix`.
- Remove `maple-mono.NF-unhinted` and the duplicate `d2coding` from `modules/core/fonts.nix`.
- Keep Monaspace, Ubuntu Mono Nerd Font, and JetBrains Mono Nerd Font as shared user fonts.
- Confirm `Maple Mono NF` and `D2Coding` still resolve through `fc-match` after switching.

### 4. Keep system-generated duplicates intact

The evaluated `environment.systemPackages` list includes duplicates generated by NixOS modules and services, including `bash`, `shadow`, desktop portals, GNOME components, and policy packages. Do not deduplicate those mechanically.

Host hardware packages such as `nvtop`, ROCm, Samsung firmware, and printer/scanner drivers are already placed appropriately and should remain unchanged.

## Verification

Run from the repository root after editing:

```console
git diff --check
nh home build .
nh os build .#ai-x1-pro
nh os build .#galaxy-book
nh os build .#nxtp-office-desktop
```

Because the Home Manager modules are shared, all three NixOS configurations should build before committing. Only switch the configuration matching the current machine's `hostname`.

After switching, verify:

```console
command -v rg fd unzip fastfetch lolcat cliphist xwayland-satellite
command -v lazydocker swaync alacritty ifconfig htop lsb_release
fc-match "Maple Mono NF"
fc-match "D2Coding"
```

The first command should resolve every retained tool. The second command should not resolve the removed tools. Finally, run `git add .`, commit the cleanup, and push `main`.
