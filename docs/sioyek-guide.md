# Sioyek 사용 가이드

공통 Home Manager 설정에서 PDF 기본 앱으로 사용합니다. `ai-x1-pro`는
Qt6/NVIDIA의 EGL 오류를 피하도록 Sioyek만 XWayland + GLX로 실행합니다.
터미널에서는 `sioyek './문서.pdf'`를 사용합니다. `nix run nixpkgs#sioyek`은
저장소에서 설정한 실행 래퍼를 사용하지 않습니다.

## Zathura 스타일 단축키

`j/k`는 애니메이션 없는 일반 이동입니다. 모든 키를 완전히 복제한 것은 아니며,
아래 표는 문서를 보는 상태를 기준으로 합니다. 입력창·목차는 Sioyek의 자체 UI입니다.

| 기능 | 키 |
| --- | --- |
| 상하좌우 이동 | `h j k l`, 방향키 |
| 다음 / 이전 페이지 | `J` / `K`, `PageDown` / `PageUp` |
| 반 화면 아래 / 위 | `Ctrl+d` / `Ctrl+u` |
| 한 화면 아래 / 위 | `Ctrl+f` / `Ctrl+b`, `Space` / `Shift+Space` |
| 처음 / 마지막 / 지정 페이지 | `gg` / `G` / `12G` 또는 `12gg` |
| 현재 페이지 위 / 아래 | `H` / `L` |
| 현재 페이지 위로 정렬 | `P` |
| 이동 이력 뒤 / 앞으로 | `Ctrl+o` / `Ctrl+i` |
| 취소 | `Esc`, 문서 보기 상태에서 `Ctrl+c` |
| 페이지에 맞추기 / 너비에 맞추기 | `a` / `s` |
| 검색 / 다음 / 이전 결과 | `/` / `n` / `N` |
| 문서 열기 | `o`, `O` |
| 링크 열기 / 링크 주소 복사 | `f` / `c` 후 링크 라벨 입력 |
| 명령 입력 | `:` |
| 시계 방향 회전 / 새로고침 | `r` / `R` |
| 색 반전 | `Ctrl+r` |
| 목차 | `Tab` |
| 두 페이지 보기 | `d` |
| 발표 모드 / 전체 화면 | `F5` / `F11` |
| 상태 표시줄 전환 | `Ctrl+n` |
| 확대 / 축소 | `+`, `zI` / `-`, `zO` |
| 마크 저장 / 이동 | `m` + 문자 / `'` + 문자 |
| 종료 | `q` |

## 완전히 같지 않은 동작

- `a`는 Sioyek의 여백을 제외한 페이지 맞춤입니다. Zathura의 best-fit과 다릅니다.
- `P`는 현재 페이지 상단으로 이동합니다. Zathura의 snap 동작을 근사합니다.
- `Ctrl+d/u`는 설정을 잠시 변경하는 매크로입니다. 숫자 접두 반복은 지원하지 않습니다.
  발표 모드에서는 Sioyek의 규칙에 따라 화면 이동 키가 페이지 이동으로 동작합니다.
- `o/O`는 파일 선택창을 엽니다. Zathura의 경로 입력창과 다릅니다.
- `:`에는 Sioyek 명령을 입력합니다. Zathura의 `:bmark`, `:print`, `:set` 등을
  그대로 지원하지 않습니다. 책갈피는 `:add_bookmark`, `:goto_bookmark`를 사용합니다.
- 목차에서 `j/k/h/l/H/L/Space`로 이동·펼치기·접기를 모두 복제하지 않습니다.
  Sioyek 목차의 검색창, 방향키, Enter, Esc를 사용합니다.
- 소문자 마크는 문서별, 대문자 마크는 전역입니다. 숫자 마크의 호환성은 보장하지 않습니다.
- 전체 화면·발표 모드별 Zathura 전용 키맵은 복제하지 않습니다.
  모드 종료는 `F11` / `F5`를 사용합니다.
- 마우스 버튼·휠 동작은 Sioyek 기본값입니다.

다음 키는 현재 패키지의 기본 명령으로 직접 대응할 수 없어 아무 동작도 하지 않게
설정했습니다. 기존 Sioyek 기능이 실행되는 혼동을 방지하기 위한 것입니다.

| Zathura 기능 | 미지원 키 |
| --- | --- |
| 가로 한 화면 / 반 화면 이동 | `t`, `y`, `Ctrl+t`, `Ctrl+y` |
| 점프 이력 이분 탐색 | `Ctrl+j`, `Ctrl+k` |
| 입력 표시줄 전환 | `Ctrl+m` |
| 역방향 검색 시작 | `?` (대신 `/` 검색 후 `N`) |
| 링크 대상 표시 | `F` (주소 복사는 `c`) |
| 두 페이지 보기의 시작 열 순환 | `D` |
| 원래 배율 / 숫자 배율 지정 | `=`, `z0`, `숫자=` (대신 `a`, `s`, `+`, `-`) |

## Sioyek 기능의 대체 키

| 기능 | 키 |
| --- | --- |
| 하이라이트 추가 | `Alt+h` |
| 정의 미리보기 | `Alt+l` |
| 최근 문서 | `Alt+o` |
| 포털 수정 | `Alt+p` |
| 선택한 텍스트 복사 | `Ctrl+Shift+c` |

Zathura 키와 충돌하는 Sioyek 기본 다중 키 조합(예: `db`, `dh`, `dp`, `c/`)은
사용하지 않습니다. 해당 기능은 `:` 명령 목록에서 실행할 수 있습니다.
시작 시 기본 키를 덮어쓴다는 경고는 의도적인 재매핑 알림입니다.

## 적용

`hms`로 적용한 뒤 Sioyek을 다시 실행합니다.

참고: [Zathura 기본 키](https://pwmt.org/projects/zathura/documentation/),
[현재 패키지의 Sioyek 명령 구현](https://github.com/ahrm/sioyek/blob/84b10d0136a976a1284931b6f5aa4976873feecd/pdf_viewer/input.cpp).
